Neel Hermes Assistant

Privacy and data handling

Effective November 17, 2026. This notice describes Neel's privately operated Hermes assistant and its dedicated Google authorization registration. It does not describe every Hermes installation.

Access and purpose

With the account holder's consent, this installation can access Gmail, Google Calendar, Drive, Docs, Sheets and contacts. The approved permissions include reading and managing email, sending email, reading and changing files and calendars, and reading contacts. Access supports the owner's requested assistant tasks, such as finding information, preparing documents and managing schedules.

Processing and sharing

Hermes runs on the owner's computer. When a task uses a cloud AI model, relevant prompts, conversation context and tool results can be sent to the selected model provider. Connected services process requests made to their APIs. The currently selected model connection uses the owner's ChatGPT or Codex subscription. Local operation does not mean that all processing stays on the computer.

This privately operated assistant is not offered to other users. Google user data is not sold or used for advertising by the operator. Any Google user data handled by this application is limited to providing or improving its user-facing assistant features, in accordance with the Google API Services User Data Policy, including its Limited Use requirements. Provider terms and account settings also apply; this notice does not promise a provider-specific retention period or training exclusion.

Storage and control

OAuth credentials are stored locally in separate account profiles with owner-only file permissions. Hermes can retain conversation history, tool results, generated files and selected memories on the owner's computer. Existing device backup arrangements may retain copies. No automatic deletion schedule has been established for these local records.

The account holder can revoke this application's access in Google Account connections. Revocation stops future authorized API access; it does not itself erase previously saved local records. The owner controls local history, memory, outputs and backups and can review or remove them through the relevant application or filesystem controls.

Contact and changes

Questions or deletion requests: neelmadanmusic@gmail.com. Update this notice before changing the installation's data uses or audience.
